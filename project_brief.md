# My agent: recipe-concierge
One-liner: A conversational agent that helps home cooks find recipes, manage their pantry inventory, and plan meals with a catalog of delicious recipes.

Tool coverage:
- Memory: Remembers user dietary preferences, allergies, and favorite cuisines
- Tools: Look up recipes in Firestore, search pantry items, add/update pantry inventory, and save favorite recipes
- Catalog/UI: Recipe catalog and pantry inventory list (renders as cards and tables)
- Image gen: Generates food dish photography for recommended recipes
- Sandbox: Calculates total nutritional macros and scaling recipe ingredient quantities

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for nutritional macro calculations
